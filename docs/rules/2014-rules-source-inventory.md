# 2014 Rules Source Inventory

## Purpose

This register identifies the exact official 2014-era rules sources authorized for implementation, testing, interpretation, and compatibility decisions.

No source is approved merely because it exists or is commonly associated with fifth-edition Dungeons & Dragons.

## Current State

**Status:** Pending Product Owner source confirmation.

No rules-content implementation may assume access to, authorization for, or precedence of a source that has not been recorded here.

## Source-Control Rules

1. Record the exact source title and relevant printing, revision, or errata state where known.
2. Distinguish access for internal implementation and testing from permission to distribute content.
3. Record later official wording that supersedes an earlier source.
4. Do not infer distribution rights from lawful access to a source.
5. Route conflicting official wording through the rules-interpretation register.
